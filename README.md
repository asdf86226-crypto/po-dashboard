# po-dashboard
발주현황 대시보드

## 재고 — 쉐어포인트(MMS)에서 가져오기

**📥 구매요청 및 재고 가져오기** 를 누르면 재고를 쉐어포인트에서 먼저 받습니다.

- 사내 로컬PC(MMS)가 평일 07~19시 매시간 이카운트 재고를 쉐어포인트 `TADC › 문서 › MMS` 에 올립니다.
- 대시보드는 회사 마이크로소프트 계정으로 로그인해 `MMS/태성정밀`, `MMS/플로우텍` 의
  `재고현황_최신.xlsx`(재고) · `품목정보_최신.xlsx`(등록 품목)를 읽고 품목코드별로 두 회사 재고를 합칩니다.
- 처음 한 번은 로그인 창이 뜹니다. 쉐어포인트를 못 읽으면 예전처럼 구매요청 대시보드(Apps Script) 재고를 씁니다.
- 공통 코드: `mms-sharepoint.js` (구매요청 · 판매현황 대시보드에도 같은 파일). 엑셀 읽기: `vendor/xlsx.min.js` (SheetJS).
- 앱 등록에 Microsoft Graph **Sites.Read.All**(위임) 권한이 있어야 합니다.

## 구매요청 대시보드와 연결

- 위쪽 **📝 구매요청 대시보드** 버튼으로 바로 이동합니다.
- 구매요청에서 가져온 발주 건의 **진행 단계 · 입고예정일**을 저장할 때마다 구매요청 Apps Script(`action: poStatus`)로 보냅니다.
  팀원은 구매요청 목록에서 "🧾 선적완료 · 입고예정 11/2" 처럼 볼 수 있습니다. **공급사 · 금액 · 송금 정보는 보내지 않습니다.**
